# SysSkills

**Universal Systems Construction Library**

A comprehensive, modular, and AI-native skills library for designing, building, evolving, and re-engineering **any software system** — from web and mobile applications to distributed platforms, cloud-native systems, and full operating systems.

![License](https://img.shields.io/badge/License-Apache_2.0-blue.svg)
![Version](https://img.shields.io/badge/version-0.1.0-orange)
[![GitHub stars](https://img.shields.io/github/stars/sys-skills/sys-skills)](https://github.com/sys-skills/sys-skills)

---

## 🎯 Vision

**SysSkills** captures battle-tested architectural knowledge, engineering practices, security principles, and system design wisdom in a structured, searchable, and executable format.

It serves as the single source of truth for:
- Senior engineers and architects
- Development teams building complex systems
- AI agents and code copilots
- Educational and onboarding programs
- Legacy system modernization initiatives

---

## ✨ Key Features

- **Technology-agnostic principles** with practical implementations
- **Hierarchical skill taxonomy** — from foundations to specialized domains
- **Proficiency levels** with clear rubrics and deliverables
- **Rich metadata** for every skill (principles, anti-patterns, code templates, decision matrices, AI prompts)
- **Cross-cutting concerns** deeply integrated (especially Security, Observability, Re-engineering)
- **Living knowledge base** — designed to evolve with the industry
- **AI-first design** — ready for LLM consumption and agentic workflows

## 🚀 How to Use SysSkills

### For Individual Engineers & Architects
- Browse skills by category or search semantically
- Follow proficiency roadmaps for career growth
- Use decision matrices when choosing technologies
- Apply ready-made checklists and templates

### For Teams & Projects
- Generate project-specific skill matrices at kickoff
- Create architecture decision records using provided templates
- Establish engineering standards and review criteria
- Support system modernization initiatives

### For AI Agents & Tools
- Consume structured YAML/JSON metadata
- Use provided LLM prompt templates per skill
- Generate code, reviews, and architecture artifacts

## 🛠 Skill Structure

Every skill contains:

- **Metadata** (YAML)
- **Principles & Mental Models**
- **Implementation Patterns**
- **Anti-patterns & Pitfalls**
- **Code Templates** (multiple languages)
- **Decision Matrices**
- **Proficiency Levels** (Awareness → Applied → Master → Architect)
- **AI Prompts**
- **References & Real-world Case Studies**
